🎮 How to Use Live Preview

  1. Open the Bulge Editor
    Press B in the main camera view or use the Filters menu → Create Custom Filter
  2. Add Bulge Points
    Click on the preview to add points. The preview updates immediately with the new bulge effect.
  3. Adjust Parameters
    Move the Radius and Strength sliders. Watch the preview update in real-time as you drag.
  4. Reposition Points
    Click and drag points on the preview to move them. The effect updates continuously as you drag.
  5. Select Points
    Click a point or select from the table to edit its properties. Blue outline = selected, Green = unselected.
  6. Create Pinch Effects
    Hold Shift while clicking to add a pinch point (negative strength). Adjust strength slider from -1.0 to 0 to control pinch intensity.
  7. Save Your Filter
    When satisfied with the preview, click "Save Filter" to persist it to the app's filter library.
💡 Tip: The preview uses a gradient texture to show the distortion clearly. Points render as circles: Yellow center = bulge, Red center = pinch

⚙️ Performance

Update Frequency
Timer updates at 30 FPS (33ms interval). Display renders at 60 FPS for smooth interaction.
Change Detection
Smart comparison skips GPU processing if no filter points changed, reducing CPU/GPU load.
GPU Processing
Metal compute shader handles distortion. Max 16 points per frame for optimal performance.
Memory Management
Test texture (853×720 BGRA8) reused. Timer cancelled in deinit to prevent memory leaks.
