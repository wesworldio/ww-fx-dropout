Critical Bug Fix Applied

🐛 Issue: Pipeline Lookup Failure

The custom bulge pipeline was being stored with a random UUID key, but retrieved with a different random UUID, causing lookups to always fail.

❌ Before (Broken)
// Store with random UUID filterPipelines[.custom(UUID())] = pipeline // Retrieve with DIFFERENT UUID filterPipelines[.custom(UUID())] // Never matches!
✅ After (Fixed)
// Store in dedicated property customBulgePipeline = pipeline // Direct access, always works guard let pipeline = customBulgePipeline
