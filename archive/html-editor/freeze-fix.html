⚡ UI Freeze Fix

Asynchronous GPU Processing for Live Preview

🔴 Problem

The Custom Bulge Filter Editor was freezing the UI when opening. The editor window appeared but became completely unresponsive to interaction.

Root Cause

The Metal GPU compute shader was being called on the main thread with a blocking wait:

// ❌ BLOCKING CALL - freezes main thread commandBuffer.commit() commandBuffer.waitUntilCompleted() // UI thread blocks here! return outputTexture

Combined with the 30 FPS timer constantly calling applyFilter(), this created a deadlock situation where the GPU work would block the main thread repeatedly.

✅ Solution

Two-Part Fix

BEFORE (Blocking)
// Main thread applyFilter() { // Direct call processCustomBulge() // BLOCKED! }
AFTER (Async)
// Main thread applyFilter() { // Dispatch to background DispatchQueue.global().async { processCustomBulgeAsync() // GPU work happens here updateTextureOnMainThread() } }

Part 1: Background Processing

Move GPU work off the main thread:

DispatchQueue.global(qos: .userInitiated).async { [weak self] in // Heavy GPU work here - doesn't block UI let filteredTexture = self?.filterProcessor.processCustomBulgeAsync(...) // Update texture back on main thread DispatchQueue.main.async { self?.metalRenderer.updateTexture(filteredTexture) } }

Part 2: Non-Blocking GPU Commit

Remove the blocking wait in GPU processing:

commandBuffer.commit() // ✓ Don't wait for completion // The GPU will process in background // Metal handles synchronization automatically return outputTexture

📝 Changes Made

BulgeEditorViewController.swift

  • Modified applyFilter() to dispatch GPU work to background queue
  • Changed from processCustomBulge() to processCustomBulgeAsync()
  • Texture updates happen back on main thread via DispatchQueue.main

FilterProcessor.swift

  • Added new public method: processCustomBulgeAsync()
  • Removed commandBuffer.waitUntilCompleted() call
  • GPU processing now non-blocking - returns immediately
  • Metal handles texture synchronization automatically

🎯 Result

  • ✅ Editor UI responsive and interactive
  • ✅ Live preview updates without freezing
  • ✅ Sliders, points, and canvas all respond instantly
  • ✅ GPU work happens in background (not blocking main thread)
  • ✅ 30 FPS timer can safely call updates repeatedly
