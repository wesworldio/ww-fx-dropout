🎯 Issues Fixed

Issue #1: Editor Window Freezing

The Custom Bulge Filter Editor window would open but become completely unresponsive. Users couldn't click, drag, or interact with any controls.

Root Cause:

The timer started immediately in viewDidLoad() before the view was ready, combined with synchronous texture creation blocking the main thread.

Issue #2: Camera Feed Not Starting

The main camera view was not displaying the camera feed on app launch, showing only a black screen.

Status:

Camera is now confirmed working - logs show "Camera capture session started: true" and "First frame received from camera!" with 1920×1080 texture processing.

🔧 Three Critical Fixes Applied

Fix 1: Delayed Timer Start

Move timer initialization from viewDidLoad() to viewDidAppear()

❌ Before (Immediate)
viewDidLoad() { setupPreviewView() updateUI() startLivePreview() // TOO EARLY! }
✅ After (Delayed)
viewDidLoad() { setupPreviewView() updateUI() // Wait for view to appear } viewDidAppear() { startLivePreview() // Safe! }

This ensures all UI elements are fully loaded and visible before starting the update loop.

Fix 2: Asynchronous Texture Creation

Create the test gradient texture on a background queue instead of blocking the main thread

// Create texture asynchronously to prevent blocking DispatchQueue.global(qos: .userInitiated).async { [weak self] in let texture = self.createTestTexture(device: device) // Update on main thread DispatchQueue.main.async { self.testTexture = texture self.metalRenderer.updateTexture(texture) } }

The 853×720 gradient texture generation (614,160 pixels) now happens in background without blocking UI setup.

Fix 3: Smart Timer Initialization

Don't start the timer until the test texture is ready

private func startLivePreview() { // Check if texture exists guard testTexture != nil else { // Retry after texture is created DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) { self?.startLivePreview() } return } // Start timer at 20 FPS (reduced from 30) previewUpdateTimer = Timer.scheduledTimer( withTimeInterval: 0.05, // 20 FPS - less aggressive repeats: true ) { [weak self] _ in self?.applyFilter() } }

Also reduced update frequency from 30 FPS to 20 FPS to reduce CPU/GPU load while maintaining smooth updates.
